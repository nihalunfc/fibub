## What it does

Look up the size of any common paper in millimetres, centimetres, inches or pixels, see two sizes drawn side by side to the same scale, and read off the percent you need to print one on the other. It covers the A, B and C series, US Letter, Legal and Tabloid, photo prints and passport photo sizes.

Nothing is sent anywhere and it works offline. To make blank pages in a size you pick, use [[printable-paper]]; to fit a picture to a size in pixels, use [[image-resizer]]; and to rearrange the pages of a PDF, use [[organise-pdf]].

## How to use it

1. Choose "Size one" and "Size two".
2. Pick the unit, and the dpi if you need pixels.
3. Read the scale lines under the picture, or browse the full table by group.

## What each setting does

- **Show in**: millimetres, centimetres or inches.
- **Pixels at (dpi)**: the pixel size of a page for a given print resolution. 300 dpi is normal for print.
- **Fit**: the scale that makes all of page one visible on page two.
- **Fill**: the scale that covers page two completely, cutting some off.

## Worked example

A4 is 210 x 297 mm. To print an A4 page on Letter (215.9 x 279.4 mm), width allows 102.8% but height allows only 94.1%, so the whole page fits at 94.1%. At 300 dpi, A4 is 2480 x 3508 pixels.

## FAQs

**What makes A sizes special?** Each size is half of the one before, with the same shape, so scaling between them is exact.

**Which passport photo size should I use?** It depends on the country and changes. Check the official source.

**Are these sizes exact?** ISO sizes are rounded to the millimetre, as in the standard.
