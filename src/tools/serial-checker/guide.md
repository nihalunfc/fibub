## What it does

Some banknotes have serial numbers that collectors like: all one digit, digits in a row, or numbers that read the same backwards. You can find them in your change or in a bundle you bought. This tool checks the digits of each serial number you paste and shows which patterns it has.

It works on a whole list at once, one serial per line, and counts how many of each pattern turned up. Letters and spaces are ignored. It only looks at the digits, so it cannot tell you what a note is worth; that depends on the country, the condition and the buyer. Record the notes you keep in [[collection-catalogue]], and judge their wear with [[grade-scale]].

## How to use it

1. Paste or type the serial numbers, one per line.
2. Read the patterns beside each one, and the summary under the table.
3. If the note is a star or replacement note, tick the box. That adds a label to each row.

## What each setting does

- **Serial numbers**: needs at least four digits per line. Letters in front, such as AB or a prefix, are ignored.
- **Star or replacement note**: you set this yourself. Printers mark replacement notes differently in each country, so the tool does not guess.
- **The list at the bottom**: explains each pattern with an example.

## Worked example

12345678 is a ladder, because the digits count up. 12344321 is a radar, because it reads the same both ways. 77777777 is both a solid (every digit the same) and a radar. Pasting all three shows "3 of 3 with a pattern: Ladder 1, Radar 2, Solid 1".

## FAQs

**Is my note worth more now?** Maybe, maybe not. Patterns interest collectors, but price depends on country, condition and demand. If you think you have a good one, ask a dealer or a collectors' club.

**Does it say whether a note is real?** No. It only reads the digits you type.

**Why are some patterns not found?** Collectors name many patterns, such as birthdays or lucky numbers, which are personal. This tool covers the common ones only.

**Is my list sent anywhere?** No. Everything runs in your browser and nothing is stored.
