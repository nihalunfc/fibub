## How it works

1. Choose a file, or drop it on the box above.
2. fibub works out what kind of file it is and suggests the best way to compress it. You can pick another way if you prefer.
3. Press **Compress**, wait a moment, then download the smaller file.

Everything happens inside your browser, on your own computer or phone. Your file is never sent anywhere, so it is safe for bank statements, IDs, contracts and other private documents.

## What each file type gets

| File type | What fibub does | Typical saving |
| --- | --- | --- |
| PDF | Repacks it, or turns scanned pages into lighter images | 10% to 95% |
| JPG, PNG, WebP | Resizes and re-saves the image; removes location data | 40% to 90% |
| Word, Excel, PowerPoint (.docx, .xlsx, .pptx) and OpenDocument | Makes the pictures inside lighter and repacks the file | Up to 90% when it holds photos |
| CSV, TXT, JSON and other text | Packs it into a ZIP | 70% to 95% |
| Older .doc, .xls, .ppt and any other file | Packs it into a ZIP | Depends on the file |

If no method makes your file smaller, fibub tells you and gives back the original. You never end up with a bigger file.

## How big a file can I compress?

Up to 200 MB on a computer and 50 MB on a phone or tablet. Your browser holds the whole file in memory while it works, and phones have much less memory to spare.
