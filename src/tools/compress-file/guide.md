## How it works

1. Choose a file, or drop it on the box above.
2. fibub works out what kind of file it is and suggests the best way to compress it. You can pick another way if you prefer.
3. Press **Compress**, pop a few bubbles while it works, then download the smaller file.

Everything happens inside your browser, on your own computer or phone. Your file is never sent anywhere, so it is safe for bank statements, IDs, contracts and other private documents. Once the page has loaded, it even works with your internet switched off.

## What each file type gets

| File type | What fibub does | Typical saving |
| --- | --- | --- |
| PDF | Repacks it, or turns scanned pages into lighter images | 10% to 95% |
| JPG, PNG, WebP | Resizes and re-saves the image; removes location data | 40% to 90% |
| Word, Excel, PowerPoint (.docx, .xlsx, .pptx) and OpenDocument | Makes the pictures inside lighter and repacks the file | Up to 90% when it holds photos |
| ZIP | Repacks the same files with the strongest compression | 0% to 30% |
| CSV, TXT, JSON and other text | Packs it into a ZIP | 70% to 95% |
| Older .doc, .xls, .ppt and any other file | Packs it into a ZIP | Depends on the file |

If no method makes your file smaller, fibub tells you and gives back the original. You never end up with a bigger file. Want to change an image's size in pixels, crop it or change its format? Use the [Image resizer](/documents/image-resizer/). Not sure whether a ZIP can get any smaller? Try the [ZIP checker](/documents/zip-checker/).

## PDF settings

| Setting | What it does | Best for |
| --- | --- | --- |
| Light | Re-packs the file more tightly. Text, links and form fields are untouched. | Text documents, forms you still need to fill in |
| Recommended | Turns each page into a sharp image at 150 DPI. | Scanned documents, ID copies, photo-heavy reports |
| Smallest | Turns each page into a lighter image at 100 DPI. | Strict limits such as 200 KB or 500 KB upload boxes |

Recommended and Smallest give the biggest savings, but the text becomes part of an image, so it can no longer be selected or searched. Keep your original file if you might need that later.

## Word, Excel and PowerPoint files

These files are really small ZIP archives: the text and layout are stored as compact data, and every picture is kept as a separate image inside. Big files are almost always big because of their photos. fibub makes each picture lighter, keeps every name and link the same so the document still finds them, and packs it all up again. Text, formatting, formulas and slides are not touched.

## How big a file can I compress?

Up to 200 MB on a computer and 50 MB on a phone or tablet. Your browser holds the whole file in memory while it works, and phones have much less memory to spare.

## Can it open password-protected files?

No. fibub does not remove passwords. Open the file in its usual app, save a copy without a password, and compress that copy.
