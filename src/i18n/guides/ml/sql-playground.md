## ഇത് എന്തു ചെയ്യുന്നു

ഡാറ്റ ഏതാനും ആയിരം വരികൾ കടക്കുമ്പോഴോ രണ്ട് ഫയലുകൾ കൂട്ടിച്ചേർക്കേണ്ടി വരുമ്പോഴോ സ്പ്രെഡ്ഷീറ്റുകൾ ബുദ്ധിമുട്ടും. SQL ഇത് രണ്ടും എളുപ്പത്തിൽ ചെയ്യും, പക്ഷേ ചില ചോദ്യങ്ങൾ ചോദിക്കാൻ മാത്രമായി ഒരു ഡാറ്റാബേസ് സെറ്റ് ചെയ്യാൻ സമയമെടുക്കും. ഈ ടൂൾ ബ്രൗസർ ടാബിനുള്ളിൽ ഒരു മുഴുവൻ SQLite ഡാറ്റാബേസ് തരുന്നു. ഫയലുകൾ തുറന്നാൽ ഓരോന്നും ഒരു ടേബിളാകും. ഓരോ കോളത്തിന്റെയും വിവരം ഉടനെ കാണാം, പിന്നെ SQL-ൽ ചോദ്യങ്ങൾ ചോദിക്കാം. നിങ്ങളുടെ ഫയലുകൾ ഉപകരണത്തിൽ തന്നെ വായിക്കുന്നു, ഒരിക്കലും അപ്‌ലോഡ് ചെയ്യുന്നില്ല. ടാബ് അടച്ചാൽ ഡാറ്റാബേസ് ഇല്ലാതാകും.

## എങ്ങനെ ഉപയോഗിക്കാം

1. ഒന്നോ അതിലധികമോ CSV, TSV, Excel (.xlsx) ഫയലുകൾ **തുറക്കുക**, അല്ലെങ്കിൽ ബോക്സിലേക്ക് ഇടുക. Excel ഫയലിലെ ഓരോ ഷീറ്റും ഓരോ ടേബിളാകും. ടേബിളിന്റെ പേര് ഫയലിന്റെ പേരിൽ നിന്നാണ്, ഉദാഹരണം `sales_2025`.
2. **വിവരം വായിക്കുക.** ഓരോ കോളത്തിനും തരം (പൂർണസംഖ്യ, സംഖ്യ, അല്ലെങ്കിൽ എഴുത്ത്), എത്ര സെല്ലുകൾ നിറഞ്ഞതോ ഒഴിഞ്ഞതോ, വ്യത്യസ്ത മൂല്യങ്ങളുടെ എണ്ണം, ഏറ്റവും കുറഞ്ഞതും കൂടിയതും, ശരാശരി, ഏറ്റവും സാധാരണമായ മൂന്ന് മൂല്യങ്ങൾ എന്നിവ കാണാം. വിശകലനത്തിനു മുമ്പ് അക്ഷരത്തെറ്റുകൾ, ഇല്ലാത്ത ഡാറ്റ, അസാധാരണ മൂല്യങ്ങൾ എന്നിവ കണ്ടുപിടിക്കാനുള്ള എളുപ്പവഴിയാണിത്.
3. **ഒരു query എഴുതുക.** നിങ്ങളുടെ ഡാറ്റ നോക്കി ഒരു ആദ്യ query നിർദ്ദേശിക്കും. **Run** അല്ലെങ്കിൽ Ctrl+Enter അമർത്തുക.
4. ഫലം CSV ആയി **ഡൗൺലോഡ്** ചെയ്യുക, അല്ലെങ്കിൽ Excel-ൽ പേസ്റ്റ് ചെയ്യാൻ **കോപ്പി** ചെയ്യുക. പേജിൽ ഫലത്തിന്റെ ആദ്യ 1000 വരികൾ കാണിക്കും, ഡൗൺലോഡിൽ എല്ലാ വരികളുമുണ്ടാകും.
5. വളരെ നേരമെടുക്കുന്ന query **നിർത്താം**. അപ്പോൾ നിങ്ങളുടെ ടേബിളുകൾ വീണ്ടും ലോഡ് ചെയ്യും.

## അറിഞ്ഞിരിക്കേണ്ടവ

- ഒഴിഞ്ഞ സെല്ലുകളും NA, N/A, null, #N/A എന്നിവയും ഇല്ലാത്തവയായി (SQL NULL) കണക്കാക്കും.
- പിൻകോഡുകൾ, 007 പോലുള്ള ID-കൾ പോലെ 0 കൊണ്ട് തുടങ്ങുന്ന സംഖ്യകൾ എഴുത്തായി തന്നെ നിൽക്കും, ഒന്നും മാറില്ല.
- കോളങ്ങളുടെ പേരുകൾ അതുപോലെ നിലനിർത്തും. സ്പേസുള്ള പേരുകൾ double quotes-ൽ ഇടുക: `"Unit price"`.
- ഓരോ ഫയലും 150 MB വരെ. ആവശ്യത്തിന് മെമ്മറിയുള്ള കമ്പ്യൂട്ടറിൽ വലിയ ഫയലുകളും പ്രവർത്തിക്കും, പക്ഷേ ഫോണുകളിൽ മെമ്മറി തീർന്നേക്കാം.

## ചെയ്തു നോക്കിയ ഉദാഹരണം

Palmer penguins ഡാറ്റാസെറ്റ് (Horst, Hill, Gorman, CC0) ലോഡ് ചെയ്യാൻ **Try it with sample data** അമർത്തുക: അന്റാർട്ടിക്കയിലെ മൂന്ന് ദ്വീപുകളിൽ നിന്നുള്ള 344 പെൻഗ്വിനുകൾ. 11 പെൻഗ്വിനുകളുടെ ലിംഗം ഇല്ലെന്ന് വിവരത്തിൽ കാണാം. നിർദ്ദേശിക്കുന്ന query `SELECT species, COUNT(*) AS n, ROUND(AVG(bill_length_mm), 2) … GROUP BY species` 152 Adelie, 124 Gentoo, 68 Chinstrap എന്നു തരും. അടുത്തതായി `SELECT island, sex, COUNT(*) FROM penguins WHERE sex IS NOT NULL GROUP BY island, sex` പരീക്ഷിക്കുക.

## പതിവു ചോദ്യങ്ങൾ

**ഇത് ഏത് SQL ആണ്?** ഏറ്റവും വ്യാപകമായി ഉപയോഗിക്കുന്ന ഡാറ്റാബേസ് എഞ്ചിനായ SQLite 3, WebAssembly-ലേക്ക് കംപൈൽ ചെയ്തത്. Window functions, CTE-കൾ (`WITH`), joins, തീയതി, എഴുത്ത് ഫംഗ്ഷനുകൾ എല്ലാം പ്രവർത്തിക്കും.

**എന്റെ ഡാറ്റ സുരക്ഷിതമാണോ?** അത് ഈ ബ്രൗസർ ടാബിൽ തന്നെ ഇരിക്കും. ഒന്നും എവിടേക്കും അയയ്ക്കുന്നില്ല, പേജ് ഓഫ്‌ലൈനിലും പ്രവർത്തിക്കും.

ഒരു ഫലം [publication plot maker](/science/plot-maker/) ഉപയോഗിച്ച് ചിത്രമാക്കാം, അല്ലെങ്കിൽ അലങ്കോലമായ ഫയലുകൾ ആദ്യം [data cleaner](/documents/data-cleaner/) കൊണ്ട് വൃത്തിയാക്കാം.
