## ഫയൽ എങ്ങനെ മാറ്റാം

1. ഒരു ഫയൽ തിരഞ്ഞെടുക്കുക, അല്ലെങ്കിൽ ബോക്സിലേക്ക് വലിച്ചിടുക. ചിത്രങ്ങളാണെങ്കിൽ ഒരേസമയം പലതും തിരഞ്ഞെടുക്കാം.
2. ഏതിലേക്കാണ് മാറ്റേണ്ടതെന്ന് തിരഞ്ഞെടുക്കുക. ആ ഫയലിന് സാധ്യമായ മാറ്റങ്ങൾ മാത്രമേ കാണിക്കൂ.
3. **Convert** അമർത്തുക, പിന്നെ **Download**.

നിങ്ങളുടെ ഫയൽ ബ്രൗസറിൽ തന്നെയാണ് മാറ്റുന്നത്, ഒരിക്കലും അപ്‌ലോഡ് ചെയ്യുന്നില്ല. പേജ് തുറന്നു കഴിഞ്ഞാൽ ഇന്റർനെറ്റ് ഇല്ലാതെയും പ്രവർത്തിക്കും.

## എന്തൊക്കെ മാറ്റാം

| ഏതിൽ നിന്ന് | ഏതിലേക്ക് |
| --- | --- |
| JPG, PNG, WebP, AVIF, GIF, BMP | JPG, PNG, WebP, AVIF (ബ്രൗസർ പിന്തുണയ്ക്കുന്നതനുസരിച്ച്), അല്ലെങ്കിൽ ഒരു PDF |
| പല ചിത്രങ്ങൾ | ഓരോന്നിനും ഓരോ പേജുള്ള ഒരു PDF, അല്ലെങ്കിൽ മാറ്റിയ ചിത്രങ്ങളുടെ ഒരു ZIP |
| PDF | JPG അല്ലെങ്കിൽ PNG (ഓരോ പേജിനും ഒരു ചിത്രം, 150 DPI), Markdown, വെറും എഴുത്ത് |
| Word (.docx) | വെബ് പേജ് (HTML), Markdown, വെറും എഴുത്ത് |
| Excel (.xlsx) | CSV (ഓരോ ഷീറ്റിനും ഒന്ന്), JSON |
| CSV | Excel, JSON |
| JSON | CSV, Excel |

## (ഇപ്പോൾ) ചെയ്യാനാകാത്തത്

ചില മാറ്റങ്ങൾക്ക് പേജുകൾ ക്രമീകരിക്കാൻ ഒരു മുഴുവൻ ഓഫീസ് സോഫ്റ്റ്‌വെയർ വേണം, അത് ഒരു സെർവറിൽ മാത്രമേ പ്രവർത്തിപ്പിക്കാനാകൂ. fibub ഒരിക്കലും നിങ്ങളുടെ ഫയലുകൾ അപ്‌ലോഡ് ചെയ്യാത്തതിനാൽ ഇവ മനഃപൂർവം ഒഴിവാക്കിയിരിക്കുന്നു:

- PDF-നെ അതേ ലേഔട്ടിൽ എഡിറ്റ് ചെയ്യാവുന്ന Word ഫയലാക്കൽ
- Word, Excel, PowerPoint എന്നിവയെ അതേ ലേഔട്ടിൽ PDF ആക്കൽ
- HEIC ഫോട്ടോകൾ (iPhone-ൽ നിന്നുള്ളവ), നിങ്ങളുടെ ബ്രൗസറിന് അവ തുറക്കാനാകുന്നില്ലെങ്കിൽ

ഇവയ്ക്ക് നിങ്ങളുടെ കമ്പ്യൂട്ടറിലെ Word, Excel, LibreOffice, Preview എന്നിവയിലെ "Save as" അല്ലെങ്കിൽ "Export" ഉപയോഗിക്കുക. അത് സൗജന്യമാണ്, ഫയൽ സ്വകാര്യമായി തന്നെ നിൽക്കുകയും ചെയ്യും.

## അറിഞ്ഞിരിക്കേണ്ടവ

- **PDF-ൽ നിന്ന് എഴുത്തിലേക്കോ Markdown-ലേക്കോ** മാറ്റുമ്പോൾ വാക്കുകളും തലക്കെട്ടുകളും ലിസ്റ്റുകളും കിട്ടും, പക്ഷേ ചിത്രങ്ങളും കോളങ്ങളും ടേബിളുകളും കിട്ടില്ല. സ്കാൻ ചെയ്ത PDF-നുള്ളിൽ എഴുത്ത് ഉണ്ടാകില്ല; അതിനെ JPG അല്ലെങ്കിൽ PNG ആക്കുക.
- **Excel-ൽ നിന്ന് CSV** ആക്കുമ്പോൾ കാണുന്ന മൂല്യങ്ങൾ മാത്രമേ സേവ് ചെയ്യൂ; ഫോർമുലകളും നിറങ്ങളും ചാർട്ടുകളും പോകും. ഓരോ ഷീറ്റും ഓരോ CSV ഫയലാകും, എല്ലാം ഒരു ZIP-ൽ.
- **CSV-യിൽ നിന്ന് Excel** ആക്കുമ്പോൾ സംഖ്യകൾ സംഖ്യകളായി തന്നെ സൂക്ഷിക്കും, അതിനാൽ ഉടനെ കൂട്ടാം. 0 കൊണ്ട് തുടങ്ങുന്ന സംഖ്യകൾ (ഫോൺ നമ്പറുകൾ, പിൻകോഡുകൾ) 0 നഷ്ടപ്പെടാതിരിക്കാൻ എഴുത്തായി സൂക്ഷിക്കും.
- **JSON-ൽ നിന്ന് CSV** ആക്കുമ്പോൾ റെക്കോർഡുകളുടെ ലിസ്റ്റ് വരികളാകും. ഉള്ളിലുള്ള ഫീൽഡുകൾ `address.city` പോലുള്ള കോളങ്ങളാകും.
- **JPG-യിൽ സുതാര്യത ഇല്ല**, അതിനാൽ സുതാര്യമായ ഭാഗങ്ങൾ വെളുപ്പാകും.
