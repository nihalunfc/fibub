## ഇത് എന്തു ചെയ്യുന്നു

പല ജൈവ പ്രതികരണങ്ങളും ഡോസിന്റെ log-നെതിരെ S ആകൃതിയിലുള്ള ഒരു വക്രം പിന്തുടരുന്നു. എൻസൈം തടയൽ, കോശങ്ങളുടെ viability, receptor binding, കളനാശിനിയോടോ ആന്റിബയോട്ടിക്കിനോടോ ഉള്ള പ്രതികരണം, antigen ഗാഢതയ്ക്കെതിരായ ELISA സിഗ്നൽ എന്നിവ ഉദാഹരണങ്ങളാണ്. ഈ വക്രത്തിനുള്ള സാധാരണ മോഡൽ **four-parameter logistic (4PL)** ആണ്. ലാബുകൾ സാധാരണ പണം കൊടുത്തുള്ള സോഫ്റ്റ്‌വെയർ കൊണ്ടാണ് ഇത് ഫിറ്റ് ചെയ്യുന്നത്. ഈ പേജ് അത് സൗജന്യമായി ബ്രൗസറിൽ ഫിറ്റ് ചെയ്യുന്നു, സാധാരണ പാക്കേജുകൾ തരുന്ന അതേ സംഖ്യകൾ തരുന്നു, അജ്ഞാത ELISA സാമ്പിളുകൾ വക്രത്തിൽ നിന്ന് വായിച്ചെടുക്കുന്നു.

## എങ്ങനെ ഉപയോഗിക്കാം

1. **ഡാറ്റ പേസ്റ്റ് ചെയ്യുക:** ആദ്യ കോളത്തിൽ ഡോസ് അല്ലെങ്കിൽ ഗാഢത, പിന്നെ ഒന്നോ അതിലധികമോ response കോളങ്ങൾ (റെപ്ലിക്കേറ്റുകൾ). പ്ലേറ്റ് റീഡർ എക്സ്പോർട്ടിൽ നിന്നോ സ്പ്രെഡ്ഷീറ്റിൽ നിന്നോ നേരിട്ട് കോപ്പി ചെയ്യാം. ഒഴിഞ്ഞ സെല്ലുകൾ ഒഴിവാക്കും, ഹെഡർ വരി ഉണ്ടെങ്കിലും പ്രശ്നമില്ല. പൂജ്യം ഡോസുകളും (കൺട്രോളുകൾ) ഫിറ്റിൽ ഉപയോഗിക്കും.
2. പ്ലോട്ടിലും റിപ്പോർട്ടിലും ലേബലുകൾ വരാൻ **ഡോസ് യൂണിറ്റിനും** **response-നും** പേര് നൽകുക.
3. നിങ്ങളുടെ ഡാറ്റ കൺട്രോളിന്റെ ശതമാനമായി normalise ചെയ്തതും വക്രം സ്വയം 0-ലോ 100-ലോ എത്താത്തതും അല്ലെങ്കിൽ, **Bottom**, **Top** എന്നിവ ഫിറ്റ് ചെയ്യാൻ വിടുക.
4. പല ELISA-കളിലും എന്നപോലെ ചിതറൽ സിഗ്നലിന് ആനുപാതികമാണെങ്കിൽ **1/Y² weighting** തിരഞ്ഞെടുക്കുക. അല്ലെങ്കിൽ weighting വേണ്ട.
5. **ELISA**-യ്ക്ക്, ഓരോ സാമ്പിളിന്റെയും absorbance ഓരോ വരിയിൽ (റെപ്ലിക്കേറ്റുകൾ ഒരേ വരിയിൽ) പേസ്റ്റ് ചെയ്ത് dilution factor ചേർക്കുക. ഓരോ സാമ്പിളിന്റെയും ഗാഢത ഫിറ്റ് ചെയ്ത വക്രത്തിൽ നിന്ന് വായിക്കും.

## മോഡലും ഫലങ്ങളും

വക്രം y = Bottom + (Top − Bottom) / (1 + (EC50 / x)^Hill) ആണ്, GraphPad Prism-ന്റെ "log(agonist) vs. response, variable slope"-ന്റെ അതേ രൂപം. പോസിറ്റീവ് **Hill slope** എന്നാൽ ഡോസിനൊപ്പം response കൂടുന്നു, മധ്യബിന്ദു **EC50**. നെഗറ്റീവ് slope എന്നാൽ കുറയുന്നു, മധ്യബിന്ദു **IC50**. ±1-നടുത്തുള്ള slope ഒരു ലളിതമായ one-site പ്രതികരണമാണ്. കൂടുതൽ കുത്തനെയുള്ള slope cooperativity സൂചിപ്പിക്കുന്നു.

ഫിറ്റ് log10(EC50)-ൽ Levenberg-Marquardt രീതി ഉപയോഗിക്കുന്നു. EC50-ന്റെ **95 % interval**, സാധാരണ പാക്കേജുകൾ റിപ്പോർട്ട് ചെയ്യുന്നതുപോലെ, log സ്കെയിലിൽ സമമിതമാണ്. standard error-കൾ ഫിറ്റിന്റെ covariance matrix-ൽ നിന്നാണ്. EC50 നിങ്ങളുടെ ഡോസുകൾക്ക് പുറത്താണെങ്കിൽ പേജ് മുന്നറിയിപ്പ് തരും, കാരണം അപ്പോൾ വക്രം നിങ്ങളുടെ ഡാറ്റയ്ക്കപ്പുറം ഊഹിച്ചതാണ്.

## ചെയ്തു നോക്കിയ ഉദാഹരണം

R പാക്കേജ് drc-യോടൊപ്പം വരുന്ന ryegrass ഡാറ്റാസെറ്റ് (Inderjit, Streibig, Olofsdotter, 2002) ആണ് സാമ്പിൾ ഡാറ്റ. കളനാശിനിയുടെ ഡോസ് കൂടുമ്പോൾ വേരിന്റെ നീളം കുറയുന്നു. ഫിറ്റ് IC50 = 3.06 mM (95 % interval 2.69 മുതൽ 3.47 വരെ), Hill slope −2.98, top 7.79 cm, bottom 0.48 cm എന്നിവ തരുന്നു. drc-യുടെ പ്രസിദ്ധീകരിച്ച LL.4 ഫിറ്റുമായും (e = 3.058, b = 2.982, d = 7.793, c = 0.481) SciPy-യുടെ curve_fit-മായും, കാണിക്കുന്ന എല്ലാ അക്കങ്ങളിലും, ഇവ ഒത്തുപോകുന്നു.

## പതിവു ചോദ്യങ്ങൾ

**എന്തുകൊണ്ട് ഒരു നേർരേഖയല്ല?** sigmoid പ്രതികരണം അതിന്റെ മധ്യഭാഗത്ത് മാത്രമേ രേഖീയമാകൂ. മുഴുവൻ വക്രത്തിലേക്കും ഒരു രേഖ ഫിറ്റ് ചെയ്താൽ രണ്ടറ്റത്തും തെറ്റായ ഫലങ്ങൾ കിട്ടും. ശരിക്കും രേഖീയമായ അസേകൾക്ക് [calibration curve tool](/science/calibration-curve/) ഉപയോഗിക്കുക.

**ഒരു സാമ്പിൾ "outside the curve" എന്ന് അടയാളപ്പെടുത്തുന്നത് എന്തുകൊണ്ട്?** അതിന്റെ response ഫിറ്റ് ചെയ്ത top-നോ bottom-നോ അപ്പുറമാണ്, അതിനാൽ ഒരു ഗാഢതയും ആ സിഗ്നൽ തരില്ല. സാമ്പിൾ നേർപ്പിച്ച് വീണ്ടും ചെയ്യുക.

**എന്റെ ഡാറ്റ അപ്‌ലോഡ് ചെയ്യുമോ?** ഇല്ല. ഫിറ്റിങ് ബ്രൗസറിൽ തന്നെ, ഒന്നും എവിടേക്കും അയയ്ക്കുന്നില്ല, പേജ് ഓഫ്‌ലൈനിലും പ്രവർത്തിക്കും.
