## ലിങ്ക് എങ്ങനെ വൃത്തിയാക്കാം

1. ബോക്സിൽ ഒരു ലിങ്ക് പേസ്റ്റ് ചെയ്യുക. ഒരുപാട് ലിങ്കുകളുള്ള ഒരു മുഴുവൻ സന്ദേശമോ ഇമെയിലോ ഡോക്യുമെന്റോ പേസ്റ്റ് ചെയ്യാം.
2. വൃത്തിയാക്കിയ രൂപം ഉടനെ കാണാം. ഓരോ ലിങ്കിനു താഴെയും നീക്കം ചെയ്ത ഭാഗങ്ങൾ വെട്ടിയ നിലയിൽ കാണിക്കും.
3. എല്ലാം കോപ്പി ചെയ്യാൻ **Copy clean text** അമർത്തുക, ഒരു ലിങ്ക് മാത്രം വേണമെങ്കിൽ അതിനടുത്തുള്ള **Copy link**.

നിങ്ങൾ പേസ്റ്റ് ചെയ്യുന്നതൊന്നും എവിടേക്കും അയയ്ക്കുന്നില്ല. വൃത്തിയാക്കൽ നിങ്ങളുടെ ബ്രൗസറിൽ തന്നെയാണ്, പേജ് തുറന്നു കഴിഞ്ഞാൽ ഇന്റർനെറ്റ് ഇല്ലാതെയും പ്രവർത്തിക്കും.

## എന്തൊക്കെ നീക്കം ചെയ്യും

- **കാമ്പെയ്ൻ ടാഗുകൾ**: `utm_source`, `utm_medium`, `utm_campaign` പോലുള്ളവ. ഏതു ന്യൂസ്‌ലെറ്ററിൽ നിന്നോ പോസ്റ്റിൽ നിന്നോ ആണ് നിങ്ങൾ വന്നത് എന്ന് ഇവ സൈറ്റിനെ അറിയിക്കും.
- നിങ്ങളുടെ ക്ലിക്കിനെ ഒരു പരസ്യ അക്കൗണ്ടുമായി ബന്ധിപ്പിക്കുന്ന **ക്ലിക്ക് ID-കൾ**: `fbclid` (Facebook), `gclid` (Google Ads), `msclkid` (Microsoft), `igshid` (Instagram), `ttclid` (TikTok), `li_fat_id` (LinkedIn) തുടങ്ങി ഒരുപാട്.
- YouTube-ന്റെയും Spotify-യുടെയും `si` പോലുള്ള **ഷെയർ കോഡുകൾ**. ഷെയർ ചെയ്ത വീഡിയോയെ ഷെയർ ചെയ്ത ആളുമായി ഇവ ബന്ധിപ്പിച്ചേക്കാം.
- **റീഡയറക്റ്റ് പൊതികൾ**: Google search, Facebook, Outlook Safe Links, YouTube description തുടങ്ങിയവയിൽ നിന്നുള്ള ലിങ്കുകൾ തുറന്ന് യഥാർഥ വിലാസം പുറത്തെടുക്കും.
- **ഷോപ്പിങ് ലിങ്കുകളിലെ അധിക ഭാഗങ്ങൾ**: ഒരു Amazon ഉൽപ്പന്ന ലിങ്ക്, ഉൽപ്പന്നത്തിന്റെ പേരും തിരഞ്ഞ വാക്കുകളും റഫറൻസ് കോഡുകളും ഇല്ലാതെ, `amazon.ca/dp/ASIN` മാത്രമാകും.
- Amazon-ന്റെ `tag`, `ref`, `aff_id`, `irclickid` പോലുള്ള **അഫിലിയേറ്റ്, റഫറൽ ടാഗുകൾ**, സ്വിച്ച് ഓണാണെങ്കിൽ. ലിങ്ക് ഷെയർ ചെയ്ത ഒരു ക്രിയേറ്ററെ തുടർന്നും പിന്തുണയ്ക്കണമെങ്കിൽ സ്വിച്ച് ഓഫ് ചെയ്യുക.

പേജിന് ആവശ്യമുള്ള ഭാഗങ്ങൾ നിലനിർത്തും: YouTube വീഡിയോ id-യും തുടങ്ങുന്ന സമയവും, തിരയൽ വാക്കുകൾ, പേജ് നമ്പർ, GitHub ബ്രാഞ്ച് എന്നിങ്ങനെ.

## ചോദ്യങ്ങൾ

**എന്തിനാണ് ലിങ്കുകൾ വൃത്തിയാക്കുന്നത്?** ആരാണ് ലിങ്ക് ഷെയർ ചെയ്തത്, നിങ്ങൾ എവിടെ നിന്നാണ് ക്ലിക്ക് ചെയ്തത് എന്നൊക്കെ ട്രാക്കിങ് ഭാഗങ്ങൾ സൈറ്റുകളെ അറിയിക്കുന്നു. ലിങ്കുകൾ നീണ്ടതും ഷെയർ ചെയ്യാൻ അഭംഗിയുള്ളതുമാക്കുകയും ചെയ്യും. വൃത്തിയാക്കിയ ലിങ്ക് അതേ പേജ് തന്നെ തുറക്കും.

**bit.ly പോലുള്ള ഷോർട്ട് ലിങ്കുകളോ?** ഷോർട്ട് ലിങ്ക് അത് എങ്ങോട്ടാണ് പോകുന്നതെന്ന് മറച്ചുവെക്കുന്നു. അത് അറിയാനുള്ള ഒരേയൊരു വഴി അത് തുറക്കുകയാണ്, അങ്ങനെ ചെയ്താൽ ഷോർട്ട്നർ സേവനം നിങ്ങളെക്കുറിച്ച് അറിയും. അതിനാൽ ഷോർട്ട് ലിങ്കുകൾ അതുപോലെ വിടുകയും അവ ചൂണ്ടിക്കാണിക്കുകയും ചെയ്യുന്നു.

**വൃത്തിയാക്കിയ ലിങ്ക് പ്രവർത്തിക്കാതെ വരുമോ?** വളരെ അപൂർവം. ഞങ്ങൾ നീക്കം ചെയ്ത ഒരു ഭാഗം പേജിന് ആവശ്യമാണെങ്കിൽ ഒറിജിനൽ ലിങ്ക് ഉപയോഗിക്കുക. ആ നിയമം ശരിയാക്കാൻ contact പേജിൽ ഞങ്ങളെ അറിയിക്കുക.
