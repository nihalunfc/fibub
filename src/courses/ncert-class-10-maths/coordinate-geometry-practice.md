**Practice · Class 10 Maths · Chapter 7.** Read the chapter lesson, [Coordinate Geometry](/learn/courses/ncert-class-10-maths/coordinate-geometry/), first. Try each question on paper before you open the answer.

<div class="bigidea">Every question here is one of two formulas. Is it about a length or about “which point”? Lengths use the distance formula; dividing, midpoints and ratios use the section formula. Write the coordinates in a neat list first (x₁, y₁, x₂, y₂) and most errors disappear.</div>

## How to set out answers

1. List the given points as A(x₁, y₁) and B(x₂, y₂) before you substitute.
2. Write the formula, then substitute with brackets, especially around negative numbers: (−3 − 2)².
3. For “prove that the points form a …” questions, find every side (and diagonals where needed) and compare the squares.
4. For section problems, write down m and n, and say which end each goes with.

## 1-mark questions

1. Find the distance of the point (12, −5) from the origin.
<details><summary>Answer</summary>√(144 + 25) = √169 = 13 units.</details>

2. Write the coordinates of the midpoint of the segment joining (3, 9) and (7, −1).
<details><summary>Answer</summary>((3 + 7)/2, (9 − 1)/2) = (5, 4).</details>

3. What is the distance between (a, 0) and (0, −a), for a > 0?
<details><summary>Answer</summary>√(a² + a²) = a√2.</details>

4. In which quadrant does the point (−4, −7) lie?
<details><summary>Answer</summary>Quadrant III, where both coordinates are negative.</details>

## 2-mark and 3-mark questions

5. Find the point on the x-axis that is equidistant from A(3, 4) and B(7, 2). *(2 marks)*
<details><summary>Answer</summary>Let P(x, 0). PA² = (x − 3)² + 16 and PB² = (x − 7)² + 4. Setting them equal: x² − 6x + 9 + 16 = x² − 14x + 49 + 4, so 8x = 28 and x = 3.5. P = (3.5, 0).</details>

6. Show that the points (1, 2), (4, 5) and (7, 8) are collinear. *(2 marks)*
<details><summary>Answer</summary>AB = √(9 + 9) = 3√2, BC = √(9 + 9) = 3√2 and AC = √(36 + 36) = 6√2. AB + BC = 6√2 = AC, so the points lie on one line.</details>

7. Find the ratio in which the point (2, 5) divides the line joining (−1, 2) and (8, 11). *(3 marks)*
<details><summary>Answer</summary>Let the ratio be k : 1. x: 2 = (8k − 1)/(k + 1), so 2k + 2 = 8k − 1 and k = 1/2. Check y: (11 × 1/2 + 2)/(3/2) = 7.5/1.5 = 5. ✓ The ratio is 1 : 2.</details>

8. The point (x, y) is equidistant from (3, 6) and (−3, 4). Prove that 3x + y − 5 = 0. *(3 marks)*
<details><summary>Answer</summary>(x − 3)² + (y − 6)² = (x + 3)² + (y − 4)². Expanding, −6x − 12y + 45 = 6x − 8y + 25, so 12x + 4y − 20 = 0, that is 3x + y − 5 = 0. This is the line of all points equidistant from the two.</details>

Fresh numbers every time. Try until you get three right in a row.

## 5-mark questions

9. Show that the points A(−2, 0), B(2, 0), C(2, 4) and D(−2, 4) form a square. *(5 marks)*
<details><summary>Model answer</summary>AB = 4, BC = 4, CD = 4, DA = 4: all four sides are equal. Diagonals: AC = √(16 + 16) = 4√2 and BD = √(16 + 16) = 4√2. The diagonals are equal. Equal sides with equal diagonals make a square (equal sides alone could be a rhombus).</details>

10. The vertices of a triangle are A(0, 0), B(6, 0) and C(3, 3). Show that it is a right isosceles triangle and find its perimeter. *(5 marks)*
<details><summary>Model answer</summary>AB = 6, BC = √(9 + 9) = 3√2, CA = √(9 + 9) = 3√2. BC = CA, so it is isosceles. BC² + CA² = 18 + 18 = 36 = AB², so by the converse of Pythagoras the angle at C is a right angle. Perimeter = 6 + 6√2 = 6(1 + √2) ≈ 14.49 units.</details>

11. Find the coordinates of the points that divide the segment joining A(−4, 2) and B(8, 11) into three equal parts. *(5 marks)*
<details><summary>Model answer</summary>The two points of trisection divide AB in the ratios 1 : 2 and 2 : 1. P (1 : 2): x = (1×8 + 2×(−4))/3 = 0, y = (1×11 + 2×2)/3 = 5, so P = (0, 5). Q (2 : 1): x = (2×8 + 1×(−4))/3 = 4, y = (2×11 + 1×2)/3 = 8, so Q = (4, 8).</details>

12. Three vertices of a parallelogram ABCD, taken in order, are A(1, 3), B(−2, 0) and C(2, −1). Find D, and check that its diagonals bisect each other. *(5 marks)*
<details><summary>Model answer</summary>D = A + C − B = (1 + 2 + 2, 3 − 1 − 0) = (5, 2). Midpoint of AC = (1.5, 1). Midpoint of BD = ((−2 + 5)/2, (0 + 2)/2) = (1.5, 1). The midpoints are the same, so the diagonals bisect each other.</details>

## Case-based question

A school is laying out a playground on a grid, one unit = 1 metre. The gate is at G(0, 0), the flag pole at F(12, 5), the water tap at T(4, 3) and the swings at S(8, 6).

(i) How far is the flag pole from the gate? (ii) Is the tap on the straight path from the gate to the swings? (iii) A bench is to be placed so that it divides the path from the gate to the flag pole in the ratio 5 : 8. Find its coordinates. (iv) Find the midpoint of the tap and the flag pole.
<details><summary>Answer</summary>(i) GF = √(144 + 25) = 13 m. (ii) GT = 5, TS = √(16 + 9) = 5 and GS = √(64 + 36) = 10. Since 5 + 5 = 10, the three points are collinear: yes, the tap is on the path (in fact exactly half way). (iii) x = (5×12 + 8×0)/13 = 60/13 ≈ 4.6, y = (5×5 + 0)/13 = 25/13 ≈ 1.9. The bench is at (60/13, 25/13). (iv) ((4 + 12)/2, (3 + 5)/2) = (8, 4).</details>

## Assertion and reason

Choose: (A) both true and R explains A; (B) both true but R does not explain A; (C) A true, R false; (D) A false, R true.

13. **Assertion:** The points (0, 0), (3, 4) and (6, 8) are collinear. **Reason:** The distances are 5, 5 and 10, and 5 + 5 = 10.
<details><summary>Answer</summary>(A). The longest distance equals the sum of the other two, which is exactly the test for collinearity.</details>

14. **Assertion:** The point (0, 5) is equidistant from (−4, 0) and (4, 0). **Reason:** The distance formula gives a different value depending on which point is taken first.
<details><summary>Answer</summary>(C). Both distances from (0, 5) are √(16 + 25) = √41, so A is true. R is false: the distances are squared, so the order never matters.</details>

<div class="keypoints">

- Distance: √[(x₂ − x₁)² + (y₂ − y₁)²]; from the origin √(x² + y²).
- Collinear: the longest of the three distances equals the sum of the other two.
- Square = four equal sides and equal diagonals; rhombus = four equal sides; rectangle = equal diagonals in a parallelogram.
- Section formula: ((m x₂ + n x₁)/(m + n), (m y₂ + n y₁)/(m + n)); the midpoint has m = n = 1.
- For a ratio along an axis, put y = 0 (or x = 0) and solve for k.
