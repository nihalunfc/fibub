**Start here · about 15 minutes.** By the end you will have a method for every question format the exams use, and you will know the trap hidden in each.

<div class="bigidea">Each question format tests the same physics, chemistry or maths, but each has its own trap. A fixed method for each format turns traps into free marks.</div>

## 1. Why formats matter

Two students who know a chapter equally well can score very differently, because one reads "which is NOT correct" as "which is correct", or marks a second option in a multi-correct question and loses everything. Every question in this course's bank carries a **format** tag so you can practise each one on purpose.

## 2. The formats, one by one

Step through them; each step gives the format, the method and the trap.

<div class="steps" data-ms="8000">
<div class="step"><b>Single answer (MCQ).</b> Four options, one right. <i>Method:</i> solve first without looking at the options when you can, then match. If stuck, test the options: put extreme values in (zero, very large, equal masses), check units, or eliminate. <i>Trap:</i> distractors are the answers to the usual mistakes (a forgotten factor of 2, a wrong sign), so "my answer is among the options" proves nothing.</div>
<div class="step"><b>Numerical (integer or decimal).</b> You type the number. JEE Main now subtracts a mark for a wrong numerical answer too. <i>Method:</i> keep symbols until the last line, then put numbers in; check the unit and the rounding the question asks for. <i>Trap:</i> no options to warn you, so a slip goes unnoticed. Always sense-check the size of the answer.</div>
<div class="step"><b>Assertion and Reason.</b> Statement A and Reason R, with four standard options. <i>Method:</i> (1) Is A true on its own? (2) Is R true on its own? (3) Only if both are true: does R explain A? <i>Trap:</i> two true statements where R is true but unrelated, or explains something else.</div>
<div class="step"><b>Statements (Statement I and II, or "how many are correct").</b> <i>Method:</i> judge each statement separately and mark it ✓ or ✗ in the margin before reading the options. <i>Trap:</i> a statement that is true in general but wrong in one word ("always", "only", "never", a wrong unit).</div>
<div class="step"><b>Match the columns (List I and List II).</b> <i>Method:</i> find the match you are surest of, cross out every option that disagrees, repeat. <i>Trap:</i> two items in List I that look alike (for example, the units of two similar quantities).</div>
<div class="step"><b>Multi-correct (one or more options correct).</b> JEE Advanced. Partial marks for each right option if you mark no wrong one; a single wrong option makes the question negative. <i>Method:</i> treat each option as a separate true/false question. Mark only the ones you are sure of. <i>Trap:</i> greed: adding a "probably" option.</div>
<div class="step"><b>Paragraph (comprehension).</b> A passage describes a new situation, followed by two or three questions. <i>Method:</i> read the questions first, then the passage with them in mind; write the given quantities in symbols. <i>Trap:</i> the later questions often depend on the first answer, so one error repeats. Check the first answer twice.</div>
<div class="step"><b>"Which is NOT correct" and mixed-chapter questions.</b> <i>Method:</i> circle the word NOT before you start. For mixed questions, name each idea the question uses (for example, "energy conservation, then circular motion") before writing equations. <i>Trap:</i> answering the opposite question.</div>
</div>

## 3. The standard options for assertion-reason

Most exams use these four options, in this or a similar order:

1. Both A and R are true, and R is the correct explanation of A.
2. Both A and R are true, but R is not the correct explanation of A.
3. A is true, but R is false.
4. A is false, but R is true. (Some papers use "both false" as a fifth or fourth option.)

<div class="myth">

**"If both statements are true, the answer is option 1."** No. Ask whether R is the reason for A. "A: A ball thrown up returns with the same speed (no air). R: The acceleration due to gravity is 9.8 m/s²." Both are true, but the reason the speed is the same is energy conservation (or the symmetry of the motion), not the value of g. The answer is option 2.

</div>

## 4. Partial marking in multi-correct questions

In a recent JEE Advanced scheme (it changes year to year): all correct options and no wrong ones = full marks; some correct options and no wrong ones = partial marks; any wrong option = negative marks. That makes each option a bet you should only place when you are sure.

<div class="meaning">
<dl>
<dt>Sure options</dt><dd>options you have proved, not guessed</dd>
<dt>Partial marks</dt><dd>marks for each correct option chosen when no wrong one is chosen</dd>
<dt>Physical meaning</dt><dd>One wrong option costs more than a missing right one, so in doubt, leave it out.</dd>
</dl>
</div>

## 5. Practise each format on purpose

In every chapter's question-types lesson, and in the practice bank, you can filter by format. Spend some sessions on one format only (for example, all assertion-reason questions across three chapters). Formats become automatic, and your thinking goes to the physics, chemistry or maths.

<div class="keypoints">

- Single answer: solve first, then match; distractors are the answers to common mistakes.
- Numerical: keep symbols to the end, check units and rounding; wrong answers can now lose marks.
- Assertion-reason: judge A, judge R, and only then ask whether R explains A.
- Statements: mark each ✓ or ✗ before reading the options; watch words like "always" and "only".
- Match the columns: use your surest match to eliminate options.
- Multi-correct: each option is its own true/false; mark only the ones you are sure of.
- Paragraph: read the questions first; check the first answer twice because later ones build on it.

</div>
