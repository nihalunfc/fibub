**Practice · Class 8 Maths · Chapter 3.** Read the lesson, [A Story of Numbers](/learn/courses/ncert-class-8-maths/a-story-of-numbers/), first. Try each question on paper before you open its answer.

<div class="bigidea">Every number system answers one question: how do we write a number so it is short and clear? Ask each time: what is each symbol worth, and does the place matter?</div>

## How to set out answers

1. For Roman numerals, break the number into thousands, hundreds, tens and ones.
2. For another base, write the place values (1, 2, 4, 8 … or 1, 5, 25 …) above the digits.
3. For conversion to base 2, show the divisions and the remainders.
4. Check by converting back.

## 1-mark questions

1. Write 29 in Roman numerals.
<details><summary>Answer</summary>XXIX.</details>

2. What does a shell stand for in Mayan numbers?
<details><summary>Answer</summary>Zero.</details>

3. Name the digits used in base 2.
<details><summary>Answer</summary>0 and 1.</details>

4. What is the place value of 6 in 36 502?
<details><summary>Answer</summary>6 000 (six thousand).</details>

## 2- and 3-mark questions

5. Write CDXLVI as a number. *(2 marks)*
<details><summary>Answer</summary>CD = 400, XL = 40, VI = 6. So 446.</details>

6. A Mayan numeral has 3 on the upper level and 12 (two bars and two dots) on the lower level. What number is it? *(2 marks)*
<details><summary>Answer</summary>Upper: 3 × 20 = 60. Lower: 12. Total 72.</details>

7. Convert 1101 (base 2) to base 10. *(2 marks)*
<details><summary>Answer</summary>1 × 8 + 1 × 4 + 0 × 2 + 1 × 1 = 13.</details>

8. Convert 26 to base 2. *(3 marks)*
<details><summary>Answer</summary>26 ÷ 2 = 13 r 0; 13 ÷ 2 = 6 r 1; 6 ÷ 2 = 3 r 0; 3 ÷ 2 = 1 r 1; 1 ÷ 2 = 0 r 1. Read from the last: 11010. Check: 16 + 8 + 2 = 26.</details>

9. Explain in two lines why the Roman numeral system is harder for big sums than the Hindu-Arabic one. *(3 marks)*
<details><summary>Answer</summary>Roman numerals have no place value and no zero, so each size needs a new letter and the digits cannot be lined up under each other for adding. In Hindu-Arabic numbers the place gives the value, so we can add column by column.</details>

## 5-mark questions

10. Write 345 in the Egyptian system (stroke 1, arch 10, coil 100) by describing the signs, and in Roman numerals, and in base 2. Which needs the fewest symbols? *(5 marks)*
<details><summary>Answer</summary>Egyptian: 3 coils, 4 arches, 5 strokes (12 signs). Roman: CCCXLV (6 letters). Base 2: 345 = 256 + 64 + 16 + 8 + 1 = 101011001 (9 digits). Hindu-Arabic 345 needs only 3 digits, the fewest of all, because place value does the work.</details>

11. A computer stores a number as 10110110 in base 2. Find the number in base 10, and say what 1 added to it would look like in base 2. *(5 marks)*
<details><summary>Answer</summary>Places from the right: 1, 2, 4, 8, 16, 32, 64, 128. The 1’s are at 2, 4, 16, 32 and 128: 2 + 4 + 16 + 32 + 128 = 182. Adding 1 gives 183 = 10110111 in base 2 (the last 0 becomes 1).</details>

## Case-based question

A school robotics club names its robot’s buttons using base 2. Button A is 101, button B is 1100 and button C is 11111 (all in base 2). The club also finds a stone inscription showing the Roman year MCMXLVII.

12. (a) Write the values of A, B and C in base 10. (b) Which button has the largest value? (c) What year does the inscription show? (d) How many digits does the base-2 name of the largest button need compared with its base-10 name?
<details><summary>Answer</summary>(a) A = 4 + 1 = 5; B = 8 + 4 = 12; C = 16 + 8 + 4 + 2 + 1 = 31. (b) Button C (31). (c) MCMXLVII = 1000 + 900 + 40 + 7 = 1947. (d) 31 needs 5 digits in base 2 (11111) and only 2 in base 10.</details>

## Assertion and reason

13. **Assertion (A):** In base 5 the number 25 is a valid number. **Reason (R):** In base 5 the digits used are 0 to 5.
<details><summary>Answer</summary>A is false as written: the digit 5 is not used in base 5 (digits are 0 to 4), so “25” is not a valid base-5 number; R is also false. Both are false.</details>

14. **Assertion (A):** Zero is important in the Hindu-Arabic system. **Reason (R):** It keeps empty places so that digits stay in the right places.
<details><summary>Answer</summary>Both are true and R explains A.</details>

15. **Assertion (A):** IIII and IV both mean 4 in Roman numerals today. **Reason (R):** A smaller letter before a bigger one is subtracted.
<details><summary>Answer</summary>The usual modern form is IV, which uses the subtraction rule R. IIII appears only on some clock faces, so A as a general rule is not correct. A is false and R is true.</details>
