**Practice · Class 11 Maths · Chapter 5.** Read the lesson, [Linear Inequalities](/learn/courses/ncert-class-11-maths/linear-inequalities/), first. Try each question on paper before you open the answer.

<div class="bigidea">Treat an inequality like an equation, but watch the sign: flip it whenever you multiply or divide by a negative number. In two variables, draw the boundary, test one point and shade.</div>

## How to set out answers

1. Do one operation per line and name it ("subtract 3 from both sides").
2. Write the final answer as an inequality and as a statement of the set (interval or number line).
3. For two variables: state the boundary line, solid or dashed, the test point, and which side is shaded.
4. Check with one number inside the solution set and one outside.

## 1-mark questions

1. Solve `$x - 4 < 7$`.
<details><summary>Answer</summary>`$x < 11$`.</details>

2. State the rule for multiplying both sides of an inequality by a negative number.
<details><summary>Answer</summary>The sign of the inequality reverses (`$<$` becomes `$>$` and `$\le$` becomes `$\ge$`).</details>

3. Is the point `$(1, 2)$` a solution of `$x + y \le 3$`?
<details><summary>Answer</summary>Yes: `$1 + 2 = 3 \le 3$` is true.</details>

4. Does the line `$x + y = 5$` belong to the graph of `$x + y < 5$`?
<details><summary>Answer</summary>No. The sign is strict, so the line is drawn dashed.</details>

5. How many natural numbers satisfy `$2x < 9$`?
<details><summary>Answer</summary>`$x < 4.5$`, so 1, 2, 3, 4: four numbers.</details>

## 2-mark and 3-mark questions

6. Solve `$4 - 3x \ge 13$` and show the solution on the number line. *(2 marks)*
<details><summary>Answer</summary>

`$-3x \ge 9$`; dividing by `$-3$` flips the sign: `$x \le -3$`. On the number line: a filled dot at −3 and shading to the left.

</details>

7. Solve `$-7 \le 3x + 2 < 14$`. *(3 marks)*
<details><summary>Answer</summary>

Subtract 2 from all three parts: `$-9 \le 3x < 12$`. Divide by 3: `$-3 \le x < 4$`. Filled dot at −3, hollow dot at 4.

</details>

8. Find all whole numbers x such that `$5x - 2 < 3x + 9$`. *(2 marks)*
<details><summary>Answer</summary>

`$2x < 11$`, so `$x < 5.5$`. Whole numbers: 0, 1, 2, 3, 4, 5.

</details>

9. A taxi charges ₹40 plus ₹12 per km. Rohan has ₹250. What is the longest trip he can afford? *(3 marks)*
<details><summary>Answer</summary>

`$40 + 12x \le 250$`, so `$12x \le 210$` and `$x \le 17.5$`. The longest trip is **17.5 km**.

</details>

10. Solve `$\dfrac{2x - 1}{3} \ge \dfrac{x + 2}{2}$`. *(3 marks)*
<details><summary>Answer</summary>

Multiply both sides by 6 (positive): `$2(2x - 1) \ge 3(x + 2)$`, so `$4x - 2 \ge 3x + 6$` and `$x \ge 8$`.

</details>

11. Graph `$3x - 2y \le 6$`. *(3 marks)*
<details><summary>Answer</summary>

Boundary `$3x - 2y = 6$` through `$(2, 0)$` and `$(0, -3)$`, solid. Test the origin: `$0 \le 6$` is true, so shade the side containing the origin (above and to the left of the line).

</details>

## 5-mark questions (model answers)

12. Solve the system `$x + y \le 6$`, `$x - y \ge -2$`, `$x \ge 0$`, `$y \ge 0$` graphically and find the corners of the region. *(5 marks)*
<details><summary>Answer</summary>

Boundaries: `$x + y = 6$` through `$(6,0)$` and `$(0,6)$`; `$x - y = -2$` through `$(0,2)$` and `$(-2,0)$`. The origin satisfies both `$0 \le 6$` and `$0 \ge -2$`, so the region contains the origin side of each line, within the first quadrant.

Corners: `$(0,0)$`, `$(6,0)$`, the meeting point of `$x + y = 6$` and `$x - y = -2$` (add: `$2x = 4$`, so `$x = 2$`, `$y = 4$`) which is `$(2,4)$`, and `$(0,2)$`. The region is the four-sided figure with these corners.

</details>

13. Find all pairs of positive integers `$(x, y)$` with `$x + 2y \le 7$`. Explain your counting. *(5 marks)*
<details><summary>Answer</summary>

For each `$x$`, `$y \le (7 - x)/2$`. `$x = 1$`: `$y \le 3$` gives y = 1, 2, 3. `$x = 2$`: `$y \le 2.5$`, y = 1, 2. `$x = 3$`: `$y \le 2$`, y = 1, 2. `$x = 4$`: `$y \le 1.5$`, y = 1. `$x = 5$`: `$y \le 1$`, y = 1. For `$x \ge 6$` there is none. That is `$3 + 2 + 2 + 1 + 1 = 9$` pairs.

</details>

## Case-based question

A school canteen sells samosas at ₹12 and fruit cups at ₹20. The canteen can prepare at most 60 items a day, and the day's ingredients allow at most ₹960 of sales. Let `$x$` be the number of samosas and `$y$` the number of fruit cups.

14. (a) Write the conditions as inequalities. (b) Is 40 samosas and 20 fruit cups allowed? (c) What is the greatest number of fruit cups possible? (d) Name the shape of the region.
<details><summary>Answer</summary>

(a) `$x + y \le 60$`, `$12x + 20y \le 960$`, `$x \ge 0$`, `$y \ge 0$`.

(b) `$40 + 20 = 60 \le 60$` and `$12(40) + 20(20) = 880 \le 960$`: yes, allowed.

(c) With `$x = 0$`: `$y \le 60$` and `$20y \le 960$` gives `$y \le 48$`. The greatest number is **48**.

(d) A four-sided figure with corners `$(0,0)$`, `$(60,0)$`, `$(30, 30)$` and `$(0, 48)$` (the lines meet where `$12x + 20(60 - x) = 960$`, giving `$x = 30$`).

</details>

## Assertion and reason

15. **Assertion (A):** If `$a < b$` then `$-a > -b$`. **Reason (R):** Multiplying both sides of an inequality by a negative number reverses the sign. Choose: (a) both true and R explains A; (b) both true, R does not explain A; (c) A true, R false; (d) A false, R true.
<details><summary>Answer</summary>(a). Taking `$-a$` and `$-b$` is multiplying by `$-1$`, which reverses the sign.</details>

16. **Assertion (A):** The system `$x + y \ge 8$`, `$x + y \le 3$` has no solution. **Reason (R):** No point lies in both half-planes. Same options.
<details><summary>Answer</summary>(a). The two half-planes are on opposite sides of parallel lines and do not overlap, which is why there is no solution.</details>
