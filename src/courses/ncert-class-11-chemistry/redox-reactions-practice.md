**Practice · Class 11 Chemistry · Chapter 7.** Read the chapter lesson, [Redox Reactions](/learn/courses/ncert-class-11-chemistry/redox-reactions/), first. Try each question on paper before opening the answer. Marks go for the oxidation numbers, the half-reactions, the balanced equation with charge checked, and the final answer with units.

<div class="bigidea">Three habits solve nearly every redox question: write the oxidation number above each atom that changes, say who loses and who gains electrons, and check that atoms and charge both balance.</div>

## How to set out an answer

1. Write the oxidation numbers of the atoms that change.
2. Say which atom is oxidised (number rises) and which is reduced (number falls).
3. Equalise electrons lost and gained, then balance charge (H⁺ or OH⁻) and then H and O (H₂O).
4. Check: atoms and charge are the same on both sides.

## 1-mark questions

1. Define oxidation in terms of electrons.

<details><summary>Answer</summary>Oxidation is the loss of electrons (the oxidation number of the atom increases).</details>

2. What is the oxidation number of oxygen in OF₂?

<details><summary>Answer</summary>+2, because fluorine is more electronegative than oxygen.</details>

3. Name a reaction type in which the same element is both oxidised and reduced.

<details><summary>Answer</summary>Disproportionation, for example 2H₂O₂ → 2H₂O + O₂.</details>

4. Why does copper not displace hydrogen from dilute acid?

<details><summary>Answer</summary>Copper is below hydrogen in the electrochemical series (E° = +0.34 V), so it cannot reduce H⁺.</details>

## 2- and 3-mark questions

5. (2) Find the oxidation number of Cr in K₂Cr₂O₇ and of S in Na₂S₄O₆, where the answer is an average.

<details><summary>Answer</summary>

Cr: `$2(+1) + 2x + 7(-2) = 0 \Rightarrow x = +6$`.

S: `$2(+1) + 4x + 6(-2) = 0 \Rightarrow x = +2.5$`, an average of S at 0 (two atoms) and +5 (two atoms).

</details>

6. (2) Identify the oxidising and reducing agents in 2Fe₂O₃ + 3C → 4Fe + 3CO₂.

<details><summary>Answer</summary>Fe goes +3 → 0 (reduced), so Fe₂O₃ is the oxidising agent. C goes 0 → +4 (oxidised), so C is the reducing agent.</details>

7. (2) Why is the reaction CaCO₃ → CaO + CO₂ not a redox reaction although it is a decomposition?

<details><summary>Answer</summary>No oxidation number changes: Ca stays +2, C stays +4, O stays −2. Decomposition is redox only when an element appears among the products.</details>

8. (3) Balance by the oxidation number method: Cu + HNO₃ (dilute) → Cu(NO₃)₂ + NO + H₂O. Show the change of oxidation numbers.

<details><summary>Answer</summary>

Cu: 0 → +2 (increase 2). N (in the NO formed): +5 → +2 (decrease 3). Multiply: 3 Cu and 2 N. So `$3\text{Cu} + 8\text{HNO}_3 \to 3\text{Cu(NO}_3)_2 + 2\text{NO} + 4\text{H}_2\text{O}$`, where 6 of the 8 nitrate ions stay as nitrate in the salt. Check H: 8 = 8; O: 24 = 18 + 2 + 4.

</details>

9. (3) Write the two half-reactions for Zn + Cu²⁺ → Zn²⁺ + Cu and say what happens if the Zn strip is replaced by Ag.

<details><summary>Answer</summary>

Oxidation: `$\text{Zn} \to \text{Zn}^{2+} + 2e^-$`. Reduction: `$\text{Cu}^{2+} + 2e^- \to \text{Cu}$`. With Ag (E° = +0.80 V, above Cu²⁺/Cu at +0.34 V) nothing happens: Ag cannot reduce Cu²⁺.

</details>

10. (3) Find the volume of 0.02 M KMnO₄ needed to oxidise 20 mL of 0.15 M Fe²⁺ in acid.

<details><summary>Answer</summary>

Fe²⁺ = 20 × 0.15 = 3.0 mmol. MnO₄⁻ = 3.0 ÷ 5 = 0.60 mmol. Volume = 0.60 ÷ 0.02 = **30 mL**.

</details>

## 5-mark questions (model answers)

11. (5) Balance MnO₄⁻ + I⁻ → MnO₂ + I₂ in basic solution by the half-reaction method.

<details><summary>Answer</summary>

Oxidation: `$2\text{I}^- \to \text{I}_2 + 2e^-$`.

Reduction: `$\text{MnO}_4^- + 3e^- + 2\text{H}_2\text{O} \to \text{MnO}_2 + 4\text{OH}^-$`.

Multiply the first by 3 and the second by 2 so that 6 electrons cancel:

`$2\text{MnO}_4^- + 6\text{I}^- + 4\text{H}_2\text{O} \to 2\text{MnO}_2 + 3\text{I}_2 + 8\text{OH}^-$`.

Charge: −8 = −8. Hydrogen: 8 = 8. Oxygen: 8 + 4 = 4 + 8.

</details>

12. (5) State the rules for assigning oxidation numbers, and find the oxidation number of each element in Fe₃O₄ and in H₂O₂.

<details><summary>Answer</summary>

Rules: free element 0; simple ion its charge; F always −1; O −2 (peroxide −1, OF₂ +2); H +1 (hydrides −1); alkali metals +1, alkaline earth +2; sum equals the charge.

Fe₃O₄: 3x + 4(−2) = 0, so x = +8/3, an average of two Fe³⁺ and one Fe²⁺. H₂O₂: H is +1, so 2(+1) + 2y = 0 and O is −1 (peroxide).

</details>

13. (5) Classify the reactions into combination, decomposition, displacement, disproportionation or non-redox, and justify with oxidation numbers: (a) 2KClO₃ → 2KCl + 3O₂; (b) Cl₂ + 2NaOH → NaCl + NaClO + H₂O; (c) Mg + 2HCl → MgCl₂ + H₂; (d) NaOH + HCl → NaCl + H₂O.

<details><summary>Answer</summary>

(a) Decomposition (redox): Cl +5 → −1, O −2 → 0. (b) Disproportionation: Cl 0 → −1 and 0 → +1. (c) Displacement: Mg 0 → +2, H +1 → 0. (d) Not redox: no oxidation number changes (neutralisation).

</details>

## Case-based question

14. **The silver spoon and the chlorine bottle.** A tarnished silver spoon (black Ag₂S) is placed in a pan of hot water with aluminium foil and baking soda. After a few minutes the spoon is bright again and a smell of rotten eggs is noticed. Another bottle labelled “bleaching liquid” (NaClO) is made by passing Cl₂ into cold NaOH solution.

(a) (1) Why does the black colour disappear?

(b) (1) Which species is the reducing agent in the spoon cleaning?

(c) (1) What is the oxidation number of Cl in NaClO?

(d) (1) Name the type of reaction in which bleaching liquid is made.

<details><summary>Answer</summary>

(a) Silver sulphide is reduced back to silver: Ag⁺ in Ag₂S gains electrons (+1 → 0).

(b) Aluminium: it is above silver in the series, loses electrons (0 → +3) and gives them to silver ions.

(c) Na is +1 and O is −2, so Cl is +1.

(d) Disproportionation: Cl₂ (0) goes to Cl⁻ (−1) and ClO⁻ (+1).

</details>

## Assertion-reason questions

Choose: (A) both true and R explains A; (B) both true but R does not explain A; (C) A true, R false; (D) A false, R true.

15. **A:** Oxidation and reduction always occur together. **R:** Electrons lost by one species must be gained by another.

<details><summary>Answer</summary>(A) Both true and R explains A: electrons are not created or destroyed.</details>

16. **A:** The oxidation number of carbon in CH₄ is −4 and in CO₂ is +4. **R:** Carbon is more electronegative than hydrogen but less electronegative than oxygen.

<details><summary>Answer</summary>(A) Both true and R explains A: C takes the shared electrons from H (so −4) but gives them to O (so +4).</details>

17. **A:** H₂O₂ can act both as an oxidising agent and as a reducing agent. **R:** Oxygen in H₂O₂ is in the intermediate oxidation state −1.

<details><summary>Answer</summary>(A) Both true and R explains A: −1 can go down to −2 (oxidising agent) or up to 0 (reducing agent).</details>
