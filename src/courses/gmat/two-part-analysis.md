**Module 8 · about 12 minutes.** By the end you will set up both parts of a Two-Part Analysis question and check your pair in seconds.

<div class="bigidea">Two-Part Analysis is two questions that share one story. Write both conditions down, solve the easier part first, and use it to find the other.</div>

## 1. What you get

A short scenario, then a table with two answer columns (for example "Adult tickets" and "Child tickets") and one shared list of five or six values. You pick one value for each column. Quant versions are usually two linked equations; verbal versions ask for, say, the assumption in one column and the flaw in the other.

## 2. The method

<div class="steps" data-title="Worked example: tickets">
<div class="step">A theatre sold 80 tickets: adults at 15 dollars, children at 8 dollars, for 1,060 dollars in total. Choose adult and child tickets.</div>
<div class="step">Conditions: a + c = 80 and 15a + 8c = 1,060.</div>
<div class="step">Multiply the first by 8: 8a + 8c = 640. Subtract: 7a = 420, so a = 60 and c = 20.</div>
<div class="step">Check both: 60 + 20 = 80 ✓; 15 × 60 + 8 × 20 = 900 + 160 = 1,060 ✓.</div>
</div>

When the algebra is long, **test the list instead**: try each value for one column, find the matching value for the other, and see whether it is in the list.

## 3. Verbal two-part questions

The same idea works with words: one column might ask for "an assumption the argument needs" and the other for "a fact that would weaken it". Use the Critical Reasoning skills from Module 6, one column at a time.

<div class="myth">

**"Once I have one part, the other is automatic."** Many wrong pairs fit one condition. The traps in the list are built that way. Check the pair against **both** conditions.

</div>

<div class="keypoints">

- Write both conditions before choosing anything.
- Solve the easier part first and use it for the other.
- Testing the list is a good plan when the algebra is long.
- The same value may answer both columns.
- Both parts must be right to score.

</div>
