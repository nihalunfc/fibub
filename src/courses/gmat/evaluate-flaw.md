**Module 6 · about 14 minutes.** By the end you will pick evaluate answers with the two-way test and name the flaw in any argument.

<div class="bigidea">Both question types point at the same weak spot in the argument. Evaluate asks what you would need to know about it; flaw asks you to name it.</div>

## 1. Evaluate: the two-way test

Stems: "Which would be most useful to know in order to evaluate the argument?" Each choice is a question. Answer it both ways:

<div class="steps" data-title="Worked example: the hand-washing checklist">
<div class="step"><i>"Since the hospital introduced a hand-washing checklist, infections fell 30%. So the checklist caused the fall."</i></div>
<div class="step">Choice: "Did infections also fall at similar hospitals without the checklist?"</div>
<div class="step"><b>Yes</b> → something else (a mild season, a new cleaning contract) probably caused the fall: the argument weakens.</div>
<div class="step"><b>No</b> → the checklist hospital stands out: the argument strengthens. One question, two directions: this is the answer.</div>
</div>

A choice whose answer would not change your view either way ("Do nurses like the checklist?") is wrong.

## 2. Flaw: name what is wrong

A flaw question describes the reasoning in abstract words ("treats a necessary condition as sufficient"). Translate each choice back into the argument before you pick.

| Flaw | Looks like |
|---|---|
| Cause from correlation | "A and B happen together, so A causes B." |
| Biased sample | Poll of gardening-site visitors speaks for the nation. |
| Reversed condition | "All X are Y; this is Y; so it is X." |
| Attacking the person | Reject the claim because of who said it. |
| Circular reasoning | The conclusion is hidden in the evidence. |
| False choice | Only two options are offered when there are more. |
| Rate vs total | A percentage change is treated as a count change. |
| Part to whole | What is true of each part is assumed true of the whole. |

<figure class="fig" data-fig="flaw-sorter"><figcaption>Read each short argument and choose its flaw. The sorter explains the answer and shows the same flaw in a business setting.</figcaption></figure>

<div class="myth">

**"Choices that describe a flaw in hard words must be wrong."** Flaw choices are always abstract. Translate the right one and it describes the argument exactly; translate a wrong one and it describes something the argument never did.

</div>

<div class="keypoints">

- Evaluate: answer each choice "yes" and "no"; the right one changes the argument both ways.
- Flaw: translate abstract choices back into the argument.
- Know the eight common flaws, especially cause from correlation, biased samples and reversed conditions.
- A flaw choice must describe something the argument actually does.
