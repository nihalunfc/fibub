**Module 3 · about 15 minutes.** By the end you will share any amount in a ratio, join two ratios, spot direct and inverse proportion and split partnership profits.

<div class="bigidea">A ratio a : b means "a parts to b parts" of the same size. Find what one part is worth and every ratio question becomes multiplication.</div>

## 2. Joining ratios

<div class="steps" data-title="Worked example: a : b = 2 : 3 and b : c = 4 : 5">
<div class="step">The two ratios share b, but b is 3 in one and 4 in the other.</div>
<div class="step">Make b the same: multiply the first by 4 (8 : 12) and the second by 3 (12 : 15).</div>
<div class="step">Now read straight across: <b>a : b : c = 8 : 12 : 15</b>, so a : c = 8 : 15.</div>
</div>

## 3. Direct and inverse proportion

```math
\text{direct: } \frac{y_1}{x_1} = \frac{y_2}{x_2} \qquad \text{inverse: } x_1 y_1 = x_2 y_2
```

<div class="meaning">

<dl>
<dt>direct</dt><dd>both grow together at the same rate: 3 pens cost ₹45, so 7 pens cost ₹105</dd>
<dt>inverse</dt><dd>one grows as the other shrinks so their product stays fixed: 6 workers take 10 days, so 12 workers take 5 days</dd>
<dt>Physical meaning</dt><dd>ask "if I double one, what happens to the other?" If it doubles, direct; if it halves, inverse.</dd>
</dl>

</div>

## 4. Partnership

Profit is shared in the ratio of **money × time** for each partner. Someone who puts in more but for fewer months may get less.

<div class="myth">

**"Adding the same number keeps a ratio the same."** 2 : 3 is the same as 4 : 6 (multiply both), but adding 1 to both gives 3 : 4, a different ratio. Questions like "what must be added to both so the ratio becomes ..." are solved with an equation, not by guessing.

</div>

<div class="keypoints">

- Total parts → one part's value → each share.
- To join a : b and b : c, make the b values equal first.
- Direct proportion: equal ratios. Inverse proportion: equal products.
- Partnership profit is shared by money × months.
