**Practice · Class 9 Maths · Chapter 2.** Read the lesson, [Introduction to Linear Polynomials](/learn/courses/ncert-class-9-maths/introduction-to-linear-polynomials/), first. Try each question on paper before you open the answer.

<div class="bigidea">Most questions reduce to three moves: put a number in for x to get p(x); set ax + b = 0 to find the zero; or put x = 0 (y-intercept) or y = 0 (zero) to find where the line meets an axis. Check signs after every step.</div>

## How to set out answers

1. Write the polynomial and name a and b with their signs.
2. For a value: substitute with brackets, then simplify.
3. For a zero: write p(x) = 0 and solve in two lines.
4. For a graph: make a table of at least three points and check they are in a line.

## 1-mark questions

1. Is 2x² + 1/x a polynomial?
<details><summary>Answer</summary>No. 1/x is x to the power −1, which is not a whole number.</details>

2. Write the degree of 9x − 4.
<details><summary>Answer</summary>1 (it is a linear polynomial).</details>

3. Find p(2) if p(x) = 5x − 3.
<details><summary>Answer</summary>5(2) − 3 = 7.</details>

4. At which point does the line y = 4x + 7 cut the y-axis?
<details><summary>Answer</summary>Put x = 0: y = 7, so at (0, 7).</details>

## 2-mark and 3-mark questions

5. Find the zero of the polynomial 3x + 12. *(2 marks)*
<details><summary>Answer</summary>3x + 12 = 0 gives 3x = −12, so x = −4.</details>

6. If p(x) = 2x − 5, find p(0), p(1) and p(−3). *(2 marks)*
<details><summary>Answer</summary>p(0) = −5, p(1) = −3, p(−3) = −6 − 5 = −11.</details>

7. For which value of k is x = 3 a zero of 4x + k? *(2 marks)*
<details><summary>Answer</summary>p(3) = 12 + k = 0, so k = −12.</details>

8. Draw the graph of y = x + 2 using three points. Where does it meet the x-axis? *(3 marks)*
<details><summary>Answer</summary>

Take x = −2, 0, 2 to get y = 0, 2, 4. The points (−2, 0), (0, 2), (2, 4) lie on a straight line. It meets the x-axis at (−2, 0), because the zero of x + 2 is −2.

</details>

Fresh numbers every time. Try until you get three right in a row.

## 5-mark questions

9. A taxi in Kochi charges ₹50 as a starting fare plus ₹12 per km. (a) Write the fare polynomial. (b) Find the fare for 9 km. (c) How far can a passenger travel for ₹206? (d) Where does the graph meet the y-axis and what does that point mean? *(5 marks)*
<details><summary>Answer</summary>

(a) F(x) = 12x + 50. (b) F(9) = 108 + 50 = ₹158. (c) 12x + 50 = 206 gives 12x = 156, so x = 13 km. (d) At x = 0, F = 50: the point (0, 50). It is the starting fare, what you pay before moving at all.

</details>

10. Find the slope of the line through (1, 5) and (4, 14), write its polynomial y = ax + b, and find its zero. *(5 marks)*
<details><summary>Answer</summary>

Slope a = (14 − 5)/(4 − 1) = 3. Using (1, 5): 5 = 3(1) + b, so b = 2. The polynomial is 3x + 2. Its zero is −b/a = −2/3. Check the second point: 3(4) + 2 = 14, correct.

</details>

## Case-based question

Anita compares two internet plans. Plan A: ₹300 fixed plus ₹4 per GB. Plan B: ₹100 fixed plus ₹8 per GB. Let x be the number of GB she uses in a month.

11. (a) Write the cost polynomials A(x) and B(x). (b) Find the cost of each plan for 20 GB. (c) For what x do the plans cost the same? (d) Which plan is cheaper when she uses 70 GB?
<details><summary>Answer</summary>

(a) A(x) = 4x + 300 and B(x) = 8x + 100. (b) A(20) = 380 and B(20) = 260, so B is cheaper at 20 GB. (c) 4x + 300 = 8x + 100 gives 200 = 4x, so x = 50 GB. (d) At 70 GB: A = 580 and B = 660, so Plan A is cheaper. The graphs cross at x = 50: below it B is cheaper, above it A is.

</details>

## Assertion and reason

12. **Assertion (A):** A linear polynomial has exactly one zero. **Reason (R):** The graph of a linear polynomial (with a ≠ 0) is a straight line that meets the x-axis at exactly one point.
<details><summary>Answer</summary>Both true and R explains A: the zero is the x-coordinate of the point where the line meets the x-axis.</details>

13. **Assertion (A):** The polynomial 0·x + 5 is a linear polynomial. **Reason (R):** Its highest power of x is 1.
<details><summary>Answer</summary>A is false: the coefficient of x is 0, so the polynomial is the constant 5, which has degree 0. R is false too, because the x-term vanishes. So A and R are both false.</details>

14. **Assertion (A):** The point (2, 7) lies on the graph of y = 3x + 1. **Reason (R):** The coordinates of every point on the graph satisfy y = 3x + 1.
<details><summary>Answer</summary>3(2) + 1 = 7, so A is true. R is true and explains A: a point is on the graph exactly when its coordinates fit the equation.</details>

<div class="keypoints">

- Polynomials have whole-number powers only; the degree is the highest power present.
- The value p(k) is found by replacing x by k; k is a zero when p(k) = 0.
- The zero of ax + b is −b/a (mind the minus sign).
- The graph of ax + b is a straight line with slope a and y-intercept b; it meets the x-axis at the zero.
- To compare two linear costs, set them equal and solve for x: that is where their graphs cross.

</div>
