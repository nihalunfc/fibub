**Practice · Class 9 Maths · Chapter 4.** Read the lesson, [Exploring Algebraic Identities](/learn/courses/ncert-class-9-maths/exploring-algebraic-identities/), first. Try each question on paper before you open the answer.

<div class="bigidea">Name the pattern before you write anything: perfect square, difference of squares, (x + a)(x + b), or a cube. Write a and b, put them in the formula with brackets, and check by multiplying out or using a number.</div>

## How to set out answers

1. State the identity you use, for example (a + b)² = a² + 2ab + b².
2. Say what a and b are in this question (for example a = 3x, b = 2y).
3. Substitute with brackets, simplify, and give the answer.
4. Check with a quick number: put x = 1 on both sides.

## 1-mark questions

1. Expand (x + 6)².
<details><summary>Answer</summary>x² + 12x + 36.</details>

2. Write 99² as (100 − 1)² and find its value.
<details><summary>Answer</summary>10000 − 200 + 1 = 9801.</details>

3. Factorise x² − 100.
<details><summary>Answer</summary>(x + 10)(x − 10).</details>

4. What is the coefficient of x in (x + 4)(x − 9)?
<details><summary>Answer</summary>4 + (−9) = −5.</details>

## 2-mark and 3-mark questions

5. Expand (3x − 2y)². *(2 marks)*
<details><summary>Answer</summary>(3x)² − 2(3x)(2y) + (2y)² = 9x² − 12xy + 4y².</details>

6. Use an identity to find 104 × 96. *(2 marks)*
<details><summary>Answer</summary>(100 + 4)(100 − 4) = 10000 − 16 = 9984.</details>

7. Factorise 9x² − 16y². *(2 marks)*
<details><summary>Answer</summary>(3x)² − (4y)² = (3x + 4y)(3x − 4y).</details>

8. Factorise x² + 7x + 12. *(3 marks)*
<details><summary>Answer</summary>

Two numbers with product 12 and sum 7 are 3 and 4, so x² + 7x + 12 = (x + 3)(x + 4). Check: x² + 4x + 3x + 12 = x² + 7x + 12.

</details>

9. If x + y = 9 and xy = 20, find x² + y² and x³ + y³. *(3 marks)*
<details><summary>Answer</summary>

x² + y² = 81 − 40 = 41. x³ + y³ = (x + y)³ − 3xy(x + y) = 729 − 3(20)(9) = 729 − 540 = 189.

</details>

Fresh numbers every time. Try until you get three right in a row.

## 5-mark questions

10. Expand (2a + b − 3c)² and check your answer with a = 1, b = 1, c = 1. *(5 marks)*
<details><summary>Answer</summary>

Use (p + q + r)² with p = 2a, q = b, r = −3c: 4a² + b² + 9c² + 2(2a)(b) + 2(b)(−3c) + 2(−3c)(2a) = 4a² + b² + 9c² + 4ab − 6bc − 12ca. Check: left = (2 + 1 − 3)² = 0; right = 4 + 1 + 9 + 4 − 6 − 12 = 0. ✓

</details>

11. (a) Expand (x + 2)³. (b) Use it to find 12³. (c) Factorise x³ − 6x² + 12x − 8. *(5 marks)*
<details><summary>Answer</summary>

(a) x³ + 3x²(2) + 3x(4) + 8 = x³ + 6x² + 12x + 8. (b) 12³ = (10 + 2)³ = 1000 + 600 + 120 + 8 = 1728. (c) It matches (a − b)³ with a = x, b = 2: x³ − 3x²(2) + 3x(4) − 8, so it equals (x − 2)³.

</details>

## Case-based question

A square park has side (x + 5) metres. A square flower bed with side 5 m is dug at one corner, and the rest is lawn.

12. (a) Write the area of the whole park by expanding (x + 5)². (b) Write the area of the lawn. (c) Factorise the lawn area. (d) For x = 15, find the lawn area in two ways.
<details><summary>Answer</summary>

(a) (x + 5)² = x² + 10x + 25. (b) Lawn = (x + 5)² − 5² = x² + 10x. (c) x² + 10x = x(x + 10). (d) x = 15: 15 × 25 = 375 m². Direct: 20² − 5² = 400 − 25 = 375 m². Same answer.

</details>

## Assertion and reason

13. **Assertion (A):** (x + 3)² = x² + 9. **Reason (R):** The square of a sum is the sum of the squares.
<details><summary>Answer</summary>Both are false. (x + 3)² = x² + 6x + 9. The cross term 2ab is missing in both A and R.</details>

14. **Assertion (A):** If a + b + c = 0, then a³ + b³ + c³ = 3abc. **Reason (R):** a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca).
<details><summary>Answer</summary>Both true and R explains A: when a + b + c = 0 the product on the right is 0.</details>

15. **Assertion (A):** x² + 12x + 36 is a perfect square. **Reason (R):** x² + 12x + 36 = (x + 6)².
<details><summary>Answer</summary>Both true and R explains A: (x + 6)² = x² + 12x + 36.</details>

<div class="keypoints">

- (a ± b)² = a² ± 2ab + b²; (a + b)(a − b) = a² − b²; (x + a)(x + b) = x² + (a + b)x + ab.
- (a + b + c)² has three squares and six cross terms; the cubes of a ± b have four terms each.
- If a + b + c = 0 then a³ + b³ + c³ = 3abc.
- Factorise by pattern: perfect square, difference of squares, or two numbers with the right sum and product.
- Always check an answer by expanding or with a test value.

</div>
