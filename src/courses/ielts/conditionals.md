**Module 9 · about 14 minutes.** By the end you will use all the conditionals accurately, especially the second conditional, which is the most useful structure in Task 2 essays.

<div class="bigidea">A conditional is a condition plus its result. The tense in each half tells the listener how real you think it is.</div>

## 1. The five patterns

| Type | Form | Use | Example |
|---|---|---|---|
| Zero | if + present, present | always true | If you heat ice, it melts. |
| First | if + present, will | real future | If it rains, we'll stay in. |
| Second | if + past, would | unreal now / hypothetical | If I had more time, I would learn to cook. |
| Third | if + past perfect, would have + pp | imagined past | If I had left earlier, I would have caught the train. |
| Mixed | if + past perfect, would + base | past cause, present result | If I had studied medicine, I would be a doctor now. |

## 2. In Task 2 essays

The second conditional is perfect for proposals and consequences:

> *If cities **charged** drivers to enter the centre, congestion **would fall** and the money **could fund** better buses.*

Other condition words: **unless** (if not), **provided that / as long as** (only if), **otherwise** (if not, then...).

> *Fare-free transport only works **provided that** services are frequent. **Otherwise**, drivers will not switch.*

## 3. In Speaking

- *If I could live anywhere, I'd choose the coast.* (Part 1: "Would you like to...")
- *If I hadn't met her, I'd never have started running.* (Part 2 stories)
- *If more people worked from home, cities would be quieter.* (Part 3 speculation)

## 4. Common errors

- ~~If I will have time, I will call.~~ → If I **have** time, I will call.
- ~~If I would know, I would tell you.~~ → If I **knew**, I would tell you.
- ~~If I had known, I would told you.~~ → I **would have told** you.

<div class="myth">

**"'If I was' is always wrong."** "If I were you" is the standard form in formal writing, but "if I was" is common in speech. In essays, use "were" for hypotheticals to be safe.

</div>

<div class="keypoints">

- Zero (facts), first (real future), second (hypothetical), third (imagined past), mixed.
- No "will" or "would" in the if-clause.
- Second conditional: the key structure for essay proposals.
- unless = if not; provided that / as long as = only if; otherwise = if not.
- In essays, prefer "if I were" for hypotheticals.
