**Module 2 · about 16 minutes · read first: [2.2](/learn/courses/lsat/main-conclusion/).** By the end you will label the job of any statement in an argument and match it to the abstract wording of the answer choices.

<div class="bigidea">Every sentence in an argument has a job. Find the main conclusion first; then each other sentence is either support for it, support for a step on the way, a view being rejected, or just background.</div>

## 1. The question stem

*"The claim that ... plays which one of the following roles in the argument?"* or *"The statement that ... figures in the argument in which one of the following ways?"* The answers are written abstractly ("It is a premise offered in support of a claim that is then used to support the conclusion"), so you need to know the five labels.

## 2. Five labels

| Label | Supported? | Supports something? |
|---|---|---|
| **Main conclusion** | yes | no |
| **Intermediate conclusion** | yes | yes |
| **Premise** (evidence) | no | yes |
| **Opposing view** (rejected) | it may be, by the other side | the author argues against it |
| **Background** | no | no, it gives context |

<div class="step" data-show="c">Main conclusion: the region should ban the pesticide.</div>
<div class="step" data-show="p1 p2 c">Premises: bees pollinate the crops; the pesticide kills bees.</div>
<div class="step" data-show="p1 p2 c">"The pesticide threatens the harvests" is supported by the premises and supports the ban: an <b>intermediate conclusion</b>.</div>
<div class="step" data-show="p1 p2 c a">"Some farmers say it is essential" is an <b>opposing view</b>: the author introduces it in order to answer it.</div>

## 3. Method

1. Find the main conclusion of the whole argument.
2. Find the statement the question names. Ask: is it supported? Does it support anything? Does the author agree with it?
3. Put your label in your own words, then find the answer that says the same thing, however abstractly.

<div class="meaning">

<dl>
<dt>"Offered in support of"</dt><dd>a premise or intermediate conclusion</dd>
<dt>"The conclusion the argument as a whole is meant to establish"</dt><dd>the main conclusion</dd>
<dt>"A position the argument aims to undermine"</dt><dd>an opposing view</dd>
<dt>"Illustrates a general claim"</dt><dd>an example given as support</dd>
<dt>Physical meaning</dt><dd>Role answers describe position in the support structure, never truth. A false-sounding statement can still be the main conclusion; a true one can be background.</dd>
</dl>

</div>

<details class="try">
<summary>Try it: a full question</summary>

"Critics of the four-day school week say it harms learning. However, schools that adopted it kept the same total teaching hours by lengthening each day, and their test scores did not fall. Moreover, teacher turnover at these schools dropped, which helps students in the long run. The four-day week is therefore worth considering for other districts."

The claim that teacher turnover at these schools dropped plays which role?

(A) It is the main conclusion of the argument.
(B) It is a premise offered in support of the argument's conclusion.
(C) It is a view the argument sets out to reject.
(D) It is background information that supports no claim.
(E) It is an example of the harm critics describe.

**Answer: (B).** It is evidence ("moreover" adds a reason) for the conclusion that the four-day week is worth considering. It is not supported by anything else, so it is not a conclusion. (C) describes the critics' view. (E) gets the direction backwards: it is a benefit, not a harm.

</details>

<div class="myth">

**"If the author agrees with a statement, it must be a premise."** The author agrees with the main conclusion and any intermediate conclusions too. What matters is whether the statement is supported, and whether it supports something else.

</div>

<div class="keypoints">

- Find the main conclusion first; label everything else by how it relates to it.
- Supported and supporting = intermediate conclusion; supporting only = premise; supported only = main conclusion.
- "Some say..." claims are usually opposing views; context is background.
- Translate your label into the abstract wording of the answers.
