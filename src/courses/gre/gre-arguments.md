<div class="bigidea">An argument is evidence plus a conclusion, joined by an unstated assumption. Find the gap and every argument question becomes easier.</div>

## 2. The negation test

<figure class="fig" data-fig="negation-test"><figcaption>Negate each choice. If the argument breaks, the choice is an assumption the argument needs.</figcaption></figure>

<div class="myth">

**"Choose what is true in the real world."** Judge each choice only by its effect on the argument.

</div>

<div class="keypoints">

- Split the argument: conclusion, evidence, gap.
- Assumption: negate it; if the argument breaks, it is needed.
- Strengthen closes the gap; weaken widens it (another cause, an untypical sample).
- Judge choices by their effect, never by real-world truth.

</div>
